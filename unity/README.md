# Wispbloom — Unity Production Rebuild

The HTML5 prototype (`../game/`) is the gameplay specification; this folder
is the premium Unity rebuild.

- `Docs/GAMEPLAY_SPEC.md` — the prototype's rules, documented (10 areas)
- `Docs/MIGRATION_MAP.md` — old system → Unity system, phasing, deviations
- `Docs/ART_MANIFEST.md` — every art asset: dims, pivots, PPU, prompts
- `Docs/VERTICAL_SLICE.md` — how to run, verify, measure, and approve
- `Wispbloom/` — the Unity 6 LTS project (URP 2D, Android portrait)

Quick start: open `Wispbloom/` in Unity 6 LTS → menu **Wispbloom → Build
Vertical Slice** → **Wispbloom → Fetch Painted Art** → Play.
